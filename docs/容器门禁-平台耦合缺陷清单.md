# 容器门禁实测缺陷清单（Linux/amd64, CGO_ENABLED=0）

> 来源：2026-10-19 `tests/container-gate.ps1` 对恢复树 src-backup 的实测输出
> 结论：本机 Windows go test 全绿，容器内 9 类失败 ⇒ 平台耦合真债

| 包 | 失败用例 | 实测现象 | 性质 |
|---|---|---|---|
| `verify` | TestRunPassAndFail / TestRunTimeout | exec: pwsh not found | 硬编码依赖 PowerShell |
| `retention` | TestTrashRefusesDangerous | C:\ 未被拒绝 | 危险路径表按 Windows 写死 |
| `web` | TestWorkspaceAPIBrowse | 返回 /boot /dev /etc 而非盘符 | 盘符概念 Windows 专有 |
| `web` | pool_api_test ×3 | 403 | 鉴权在 Linux 行为不符 |
| `web` | TestGovSummaryAndSample | 期望 unverified 实得 red | 首启无采样语义 |
| `modelpool` | TestSyncAutoRevivesAutoDisabledModel | enabled=false | 恢复逻辑平台相关 |
| `modelpool` | TestFailoverStopsOnRateLimit | 限流仍换模型 3 次 | 限流语义 |
| `judge` | TestJudgePrefersStructuredErrorKind | bad_exit 覆盖 rate_limited | 错误分类被空产出覆盖 |
| `supervisor` | TestWriteCSVIsIncremental | 6 行历史只剩 3 行 | 增量落盘 Linux 失效 |
| `autonomy/config/executor/gov` | build failed | 测试引用不存在字段 | 跨快照拼接残留 |
