## 2. 界面之间的关系（一张有向图读懂）

```
        ┌──────────────── 首页 /（唯一按钮，无导航） ────────────────┐
        │  隐藏后门「·」 → /admin                                     │
        ▼                                                            │
   管理面板 /admin ──顶栏──► 模型池 /modelpool ──顶栏──► 管理面板      │
        │  │                     │  ▲                                  │
        │  └────顶栏「治理」─────┐│  └──顶栏──► 治理 /governance ────────┘
        │                        ▼▼                  │  ▲
        └── 10 页签（#overview … #settings，可 hash 深链） │  │
                                                       └──┘  │
        治理控制台 ──顶栏──► 管理面板 / 模型池 / 首页 ◄───────┘
```

- **首页**（2026-10-19 改版）：按钮负责启动/进入，入口条负责直达——「管理面板 / 模型池 / 治理」三个链接可见地摆在页面上，旧隐藏后门按老大当轮指令退役（P0.19：当轮命令 > 既往口径）。
- **管理员面**是枢纽：向上有治理与模型池两个兄弟界面，向下有 10 个功能页签。
- **模型池 / 治理控制台**是同级的专用界面：各自只解决一件事，且互相可达、都能回首页。
- **hash 深链**把「页签」提升为可引用状态：`/admin#logs` 可以被书签、被浏览器返回/前进、被刷新保留。

## 3. 本轮补的缺口（此前不可达 / 不可回溯）

| 缺口 | 现象（改动前） | 修法 | 判据 |
|---|---|---|---|
| 治理控制台**不可达** | admin 顶栏只有「模型池 / 回首页」，`/governance` 只能手输 URL | admin 顶栏加「治理」入口；governance 顶栏加「模型池」(与 admin 对等) | `TestSubpagesAreMutuallyReachable` |
| 页签状态**不可回溯** | 切页签只改 class，换页/刷新/返回全回概览；无法引用「日志」页 | appJS 加 hash 深链（`activateTab` + `hashchange`），非法 hash 回落 overview | `TestPanelScriptSupportsHashDeepLink` + CDP 实测四态 |
| 模型池车道表**窄屏裸数字** | ≤720px 卡片模式用 `td::before{content:attr(data-label)}` 显示字段名，车道表 5 格没有 data-label | 补 data-label（车道/总数/可用/下线/停用） | `TestPoolLaneCellsCarryDataLabel`（由 pool-ui 交付） |
| 模型池行内按钮**触控不达标** | 操作按钮高度 < 44px | 页内媒体查询补 `.pool-row-actions button{min-height:44px}` | `TestPoolRowActionButtonsMeetTouchBaseline` |
| `--ui-probe` **主入口缺失** | 主二进制跑 `--ui-probe` 会回落成 GUI 启动 → 前端验收没有确定性通道，只能人工走查 | main.go 补回 `case "--ui-probe"` | 见 §4 探针就绪输出 |
| 首页入口**启动窗口内被吞** | 开屏自动启动在途时点按钮被 `inflight` 裸 return 吞掉、busy 态 `lock:true` 不派发 click——「点了没反应」；CDP 拖慢 start 6s 复现：9s 内 URL 从未离开 `/` | busy 改 `lock:false`；在途点击记 `pendingEnter`，启动收敛后补 `enterPanel()`（吞请求不吞意图） | `TestHomeEntryPromise`（Go 契约）+ 探针 `home-enter` 用例（真实点击→落地 `/admin?token=`），门禁 18→19 |
| 前端探针**只判异常（假绿）** | `cdp_probe.mjs` 无条件 `status:"ok"`，页面越界/半激活/报错全判绿 | 加断言层（probe-ui 交付中，见 docs/前端探针判据修复-2026-10-19.md） | 见 T2 交付 |

## 10. 开箱即用（本轮老大追加要求：全自动、零人工步骤）

### 10.1 一条命令的前端门禁（新增，零提示）

```powershell
node D:\workdesktop\tests\ui\frontend-gate.mjs --md D:\workdesktop\docs\前端门禁回执-latest.md
# 或双击 D:\workdesktop\前端自检.cmd
```

它把原先**必须人工**的三步合成一步：

| 原先（人工） | 现在（自动） |
|---|---|
| 手工 `Start-Process workbench.exe --ui-probe --dir … --port …` | 自动挑空端口、自动起隔离实例、自动收尾 taskkill |
| 打开 `ui-probe.url` 抄 token | 脚本自己读 `ui-probe.url` 第 2 行 |
| 把 token 贴进 cdp_probe 命令行 | 自动传参；并自动挑一个空闲 CDP 端口（默认 9222 是全局共享的） |

判定三态：**PASS（0）／FAIL（2）／UNVERIFIED（3）**，并落一份 markdown 回执。
「没测成」永远不会被算成 PASS —— 这是本仓一贯口径。

### 10.2 无人值守静态门禁（并行会话交付，Lead 独立复核 rc=0）

```
powershell -NoProfile -NonInteractive -File tests\check_noninteractive.ps1
→ 无人值守合规：扫描 33 个脚本，0 处会等人工按键的构造   CHECK_RC=0
```

判据：① 任何 `Invoke-WebRequest` 必须带 `-UseBasicParsing`（PS 5.1 缺它会走 IE 引擎解析页面，
页面含 `<script>` 时弹出 `Security Warning: Script Execution Risk` 并**挂起等人按键**，
对 7×24 无人值守就是永久卡死）；② 注册计划任务的命令行必须带 `-NonInteractive`；③ 禁 `Read-Host`/`Get-Credential`/`ShouldContinue`/`Out-GridView`/裸 `-Confirm`。

## 11. 首页「极简」的机器判据（目标要求 1 逐条对照）

| 目标原话 | 判据 | 实测 |
|---|---|---|
| 首页保持极简 | `indexHTML` 里 `<button` 恰好 1 个、`<a ` 恰好 1 个（隐藏后门） | 契约测试 + 截图 |
| 只保留一个居中的「开始」按钮 | 可见元素只有那一颗按钮；`<div>/<p>/<img>/<svg>/<h1>/<nav>/<input>…` 一律禁止 | `TestIndexPageNoRedundantVisibleElements` |
| 不添加标题、菜单、设置项或其他任何控件 | 无 `<nav>`、无 `role=menu`、无表单控件、无可见状态文字（状态区 `.sr-only`） | 同上 |
| 点击后进入主功能子界面 | 点击 → 启动（若未运行）→ 2.2s 后 `location` 变为 `/admin` | CDP 四态实测：`onHome={url:"/",label:"工作台"}` → `1200ms 仍在 /` → `4200ms url="/admin"` |
