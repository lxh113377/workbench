# 个人 AI 工作台 · 使用说明

> 一个 Windows 桌面端 7×24 小时全自动 AI 产出工作台。双击启动 → 点「开始运行」→ 它自己找任务、自己评估、自己执行、自己延伸。

---

## 一、30 秒上手

1. **双击桌面图标**「个人AI工作台」
2. 浏览器自动打开极简首页，页面中央只有一个按钮：**开始运行**
3. 点击它
4. 完成 —— 之后它会持续产出，不需要你再做任何事

关闭浏览器窗口不会停止工作台：它驻留在系统托盘。任务照常跑。

---

## 二、它到底在干什么

工作台跑的是一个**闭环**，每一圈都不需要人：

```
① 生成任务     从 24 条内置模板里选题（6 大领域轮转）
② 智能评估     三维打分：产出价值 / 资源成本 / 可行性 → 综合分
③ 自动批准     综合分 ≥ 阈值（默认 60）才进队列，否则直接拒掉
④ 排队调度     优先级 + 先进先出；同一条链串行，保证上下文连贯
⑤ 执行产出     调用 DSH Desktop（our-free-model 无限额度）真实生成内容
⑥ 归档 + 自评  落盘 Markdown，判 1-10 分，打标签，指出不足
⑦ 延伸后继     依据前一份成果生成下一环任务（上下文自动注入）
                 └→ 回到 ①，形成自我延续的产出链
```

**为什么不会产出没意义的任务？**
四重约束叠在一起：
- 模板先验（每条模板都有价值先验分）
- 新颖度（与最近 50 条产出的相似度反向计分）
- 硬门禁（完全重复 / 高相似 / 冷却期 / 每日上限 直接拒）
- 用户纠偏（打星会回灌到后续价值计算）

## 三、界面说明

### 极简首页（唯一主按钮）
- **开始运行** —— 启动引擎。运行中会变成灰色的「运行中…」
- 右下角极小的「面板」二字 —— 进入管理面板（主视觉里刻意压制，不干扰）

### 管理面板（7 个页签）

| 页签 | 能做什么 |
|---|---|
| **概览** | 引擎状态、今日产出、队列长度、累计完成、成功率、平均耗时、总产出量、模型健康度、快捷操作 |
| **队列** | 看调度队列（优先级 + FIFO）；置顶、终止、查详情；手动添加任务（会自动评估） |
| **产出** | 所有已完成成果，可预览 Markdown、打星、一键导出 MD / TXT / Word |
| **模板** | 模板库 CRUD：新建、编辑、删除、恢复默认。每个模板可配描述/Prompt/优先级/价值先验 |
| **评估** | 三维权重滑杆、自动批准阈值、每日上限、去重阈值、语义判分开关、重复门禁开关；支持「试评估」 |
| **日志** | 审计流水（谁在什么时候把哪个任务从什么状态改到什么状态）、错误任务及重试 |
| **设置** | 并发数、超时、重试次数、链深度/扇出/最低质量分、开机自启、系统自检、停止引擎 |

## 四、你可能想调的 5 个东西

### 1. 产出太多 / 太少
面板 → **评估** → 调「自动批准阈值」：
- 调高（80+）= 只留高价值任务，产出变少变精
- 调低（40）= 什么都做，产出变多

### 2. 想跑得更快
面板 → **设置** → 「并发执行数」（1-6）：
- 2 是默认值，稳定且不抢占桌面端资源
- 想快就调 3-4；调太高会明显占用内存（每个任务是一个独立的 DSH 进程）

### 3. 想让内容更深入
面板 → **设置** → 「链最大深度」（默认 5）与「每链扇出」（默认 2）：
- 深度越大，一条链会一路深挖下去（深度 8 = 连续 8 层递进）
- 扇出越大，每个成果会分出更多分支

### 4. 想加自己的任务方向
面板 → **模板** → 「新建模板」。必填项：
- **ID**：英文唯一标识，如 `my-market-report`
- **Prompt 模板**：必须含 `{topic}` 占位符
- 其余：优先级（1-5）、价值先验（0-100）

保存后立刻进入模板池参与轮转。

### 5. 想立刻塞一个任务
面板 → **队列** → 底部「手动添加任务」：
填标题 + 描述 → 点「评估并加入队列」。它会先过三维评估，通过了才入队。

## 五、导出成果

面板 → **产出** → 三个按钮：

| 按钮 | 产物 |
|---|---|
| 导出全部 Markdown | 一份 `.md` 合集（含标题、元信息、正文） |
| 导出全部 TXT | 一份纯文本合集（已去掉 Markdown 标记） |
| 导出全部 Word | 一份 `.docx`（真 OOXML，Word / WPS 可直接打开） |

导出文件位置：`<程序目录>\workbench-output\exports\`

---

## 六、开机自启

面板 → **设置** → 「随 Windows 启动」→ 勾选 → 点「应用」。

- 开启后写入 `HKCU\...\Run`，重启系统会自动以 `--silent` 后台启动
- 会**恢复上次运行状态**：上次是运行中，重启后自动继续跑
- 关闭同理，点掉勾选 → 应用

## 七、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击没反应 | 已有实例在运行（单实例锁） | 看托盘图标；或访问 `http://127.0.0.1:17890/` |
| 首页打开一片空白 | 端口被占，程序换了端口 | 看 `runtime\panel.url` 文件里的真实地址 |
| 任务全部失败「没有可用模型」 | 模型池全部进入冷却 | 面板 → 概览 → 模型健康度；等冷却结束或运行 `workbench.exe --diagnose` |
| 提示「执行通道探测失败」 | DSH Desktop 未安装 / 路径变了 | 装回 DSH Desktop；或用环境变量 `DSH_DESKTOP_EXE` 指定 |
| 产出是空的 | 模型调用成功但没输出文本 | 面板 → 日志 → 错误任务 → 重试 |
| 托盘图标不见了 | Explorer 重启过 | 重新启动程序（会自动接管） |

### 命令行（无需界面，可脚本化）

```powershell
workbench.exe --version          # 版本
workbench.exe --status           # 当前状态（JSON）
workbench.exe --diagnose         # 完整自检（含 DSH 通道探测）
workbench.exe --setup            # 重建桌面/开始菜单快捷方式
workbench.exe --export-all D:\out # 导出全部产出到指定目录
workbench.exe --stop             # 标记停止
workbench.exe --silent           # 后台启动（开机自启用）
```

## 八、目录结构

```
dist\workbench.exe               ← 唯一程序文件
dist\workbench-output\           ← 全部数据（可整体备份/迁移）
  ├─ config.json              配置
  ├─ queue.json               任务队列（含全部历史）
  ├─ state.json               引擎状态
  ├─ templates.json           你的自定义模板
  ├─ tasks\<id>\
  │   ├─ final.md             成果正文
  │   ├─ events.jsonl         完整执行事件流（可追溯）
  │   ├─ overlay.yml          该任务用的模型配置
  │   └─ workspace\           任务工作目录
  ├─ exports\                 导出的合集
  └─ logs\
      ├─ audit.jsonl          审计流水（状态迁移全记录）
      ├─ metrics.csv          资源采样（内存/句柄/goroutine）
      └─ crash.log            panic 记录（正常应为空）
dist\runtime\                    ← 运行环境（自动建立，勿手改）
  ├─ dsh-home\                  隔离的 DSH 运行目录
  ├─ panel.url                 当前面板地址
  └─ workbench.lock            单实例锁
```

## 九、它有多稳

- **崩溃自愈**：每个 goroutine 都有 panic 兜底，单点异常不会带崩整个引擎
- **断点续跑**：进程被强杀 / 断电后重启，已完成任务零重跑，运行中任务自动重新入队
- **卡死回收**：任务 180 秒无任何进展会被判定卡死，进程树整棵回收并重试
- **资源自愈**：堆内存 > 700MB 或句柄 > 3000 连续 3 次采样触发 → 自动重启自身并恢复
- **模型熔断**：某模型连续失败进入冷却，自动切换到其他模型；整池不可用时任务重新排队而非判死

## 十、隐私与边界

- 工作台**只监听 127.0.0.1**，不对外网开放
- 所有数据都在本机 `workbench-output\` 目录
- 不修改你的 `~/.dsh` 配置与桌面端数据（只**读**取账号态与插件目录）
- 任务通过 DSH Desktop 自身的 our-free-model 通道执行，额度与账号状态和桌面端一致
