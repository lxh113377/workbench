# 界面简化「信息架构收敛」— 2026-10-20（ds 端）

> 老大当轮原话：**「页面乱七八糟的东西太多了，不够简洁，对用户不友好」**。
> 本轮不是换皮，是**信息架构手术**：把「什么都摆出来」改成「先给结论，要看再展开」。
> 全部改动落在 `workbench/internal/web/`（Go 内嵌字符串，零外部依赖），
> 发布件 `dist\workbench.exe` v1.3.0 已换件并双重复验。

## 1. 病根诊断（先量后改）

拿旧版四页截图逐页走查 + 读源码，冗余集中在四处，且不是「颜色难看」而是**信息过载**：

| # | 症状 | 证据 |
|---|---|---|
| 1 | 管理面板 **10 个页签**平铺：概览/队列/产出/模板/自主/评估/日志/治理/工作目录/设置 | 一屏 10 个入口没有主次，鼠标要横着找 |
| 2 | 总览首屏 **10 张 KPI 卡**（含降级任务/被拒任务/产出总量这类低频读数） | 1440px 下两行读数墙，真正的「今天产出了多少」反而被淹没 |
| 3 | 次级信息全平铺：模型健康度表、运行时指标 4 格、失败分布表、最近错误、快捷操作 **5 张卡顺排** | 页面 1414px，绝大多数时间是空的/恒定的 |
| 4 | 模型池：9 列模型表 + 常显 12 字段添加表单 + 车道表 + 日志 | 一屏 1228px，其中添加表单常显占一屏 |
| 5 | 治理台：hero 结论带下面又一条 **banner 把同样的等级/契约/采样再念一遍** | 重复信息 = 纯视觉噪音；首启无数据时铺 7 张全 0 卡 |

## 2. 改法（五条统一原则）

1. **页签收敛**：10 → **5**（总览 / 任务 / 产出 / 模板 / 设置）。自主+治理并入总览，
   评估+工作目录+审计日志并入设置。旧深链 `#logs` / `#evaluate` / `#workspace` 等
   由 `LEGACY_TABS` 映射到合并后的页签，**老书签不失效**（hash 原样保留，不改写用户历史）。
2. **首屏只放 4 个用户真正关心的读数**：今日产出 / 排队中 / 成功率 / 累计完成。
   其余 6 个读数删除或降级进折叠块。
3. **次级信息一律折叠**（`<details class="fold">`）：模型健康度、运行时资源、失败原因、
   最近错误、评估权重、换工作目录、访问审计、操作流水、失败任务。
   折叠标题行本身就是「这一块是什么」，点开才铺明细。
4. **空态说人话**：一句话说清「这里现在没东西 / 去哪里弄」，不再是一整块空白 + 一行小字。
5. **顶栏收敛**：暂停/继续/停止直接可见，**跨页入口收进「更多」菜单**（原来一排 6 个按钮 + 3 个链接）。

### 2.1 管理面板

- 页签 10 → 5；顶栏 6 按钮 + 3 链接 → 3 按钮 + 1「更多」。
- 总览：4 KPI + 一行状态摘要（引擎/执行中/平均耗时/验收率）+ 4 个折叠块。
- 任务：原「调度队列」+「执行中/待执行」两张表合成为「正在排队」「执行中的任务」，
  手动加任务表单收进折叠；空态改成「队列是空的 —— 引擎会自动从模板生成任务」。
- 产出：一行「共 N 份 / M 份通过验收」+ 表格；导出按钮收进折叠。
- 设置：常用项（并发/超时/重试/链深）直接可改；评估权重、换工作目录、访问审计、
  操作流水、失败任务全部折叠。
- 治理结论（原独立页签）保留 hero 结论带 + 考核矩阵，明细四卡折叠。

### 2.2 模型池

- 9 列 → **6 列**：删掉「延迟」「最近错误/备注」两列（桌面上半数行是「—」或空串），
  把延迟与备注合并成模型名下方一行小字。
- 行内操作 6 个 → **4 个高频**（↑ ↓ 停用/启用 编辑）+ 1 个「⋯」收纳恢复/删除（低频破坏性动作）。
- 添加表单从「常显 12 字段」改为「一个按钮 → 折叠展开」；高级参数（车道/Tier/权重/阈值/冷却）再折一层。
- 车道水位表并入总览卡折叠块（它本来只是「这几条车道各几个模型」）。
- 状态日志折叠。

### 2.2.1 非技术用户视角（v1.3.1 补做）

老大不是技术人员（behavior_core #25③）。除了「东西太多」，「看不懂」同样是不友好：

| 原标签 | 改成 | 为什么 |
|---|---|---|
| 线协议（openai-chat / openai-responses / anthropic-messages） | **接口类型**（OpenAI 标准对话 / OpenAI Responses / Anthropic 格式） | 「线协议」是协议栈行话，用户只关心「我这个接口是哪种」 |
| Tier（quality / balanced / fast） | **用途偏好**（质量优先（慢一点，写得好）/ 均衡（默认）/ 速度优先（快，短任务用）） | 括号里把代价讲清楚，用户能自己选 |
| 车道（custom/free/kilo/eac/aggregate） | **线路来源**（我自己填的接口 / 工作台自带免费通道 / …） | 「车道」是内部调度概念 |
| BaseURL | **接口地址（BaseURL）** | 保留英文便于对照文档，但中文在前 |
| DSH profile | **运行配置**（一般不用改） | 用户不需要知道 DSH 是什么 |

模板库另做两件事（原来 24 行全平铺、无搜索，是管理面板最长的一页）：
默认只渲染**价值先验最高的 8 个** + 「还有 N 个，全部展开」；加搜索框（按模板名/领域过滤，250ms 去抖）。

### 2.3 治理台

- 顶栏与另两页统一：**刷新 + 立即采样（主按钮）+「更多」**，跨页入口收进菜单（原来 5 个按钮平铺）。
- **删除与 hero 完全重复的 gov-banner**（同样的等级/契约/采样/考核念两遍）。
- 首启无数据时不再铺 7 张全 0 卡，改为一句「治理台要靠采样才有读数，点右上角立即采样」+
  其余明细折叠（如实标注「未验证」而不是假装有数据）。
- 风险预警 / 考核校验保持展开（结论面），四个取证明细卡折叠。

### 3.1 顺手修掉一个门禁自身的假绿隐患（重要）

改判据时发现门禁回执里写着 **「用例数=20/19」** —— 探针新增了 `legacy-hash-admin` 用例，
但 `frontend-gate.mjs` 的 `EXPECTED_CASES` 还停在 19。它不只是显示难看：
该常量是「结果集完整」的唯一判据，**写小了就等于允许漏跑用例仍判 PASS**，
和此前 `cdp_probe.mjs` 无条件写 `status:"ok"` 是同一类假绿，只是发生在门禁层。

修法：① 常量 19 → 20；② 增加**启动前自检**——从 `cdp_probe.mjs` 源码里数出真实用例数，
与常量不一致就 `process.exit(3)` 硬停（不给结论，避免整轮白跑后还判 PASS）。
双向验证过：故意把常量改成 19 → rc=3 且打印差异；正常跑 → 自检通过 + PASS。

## 3.2 二轮反馈修的两个真缺陷（v1.3.2）

老大发来一张真实窗口截图（1040×613）指出：任务页三张卡两张只有「没有」，且页签条像被切掉半截。
两个都不是观感问题，是**可复现的渲染缺陷**：

### 缺陷 A：页签条被 flex 压成 0 高度（真 bug）

CDP 实测读数：`.tabs` 的 `height = 0`，而内部 `.tab` 高 46px —— 页签溢出父容器、叠到下面卡片上。
根因：`body.admin` 是 `display:flex;flex-direction:column`，而 `.tabs` 带 `overflow-x:auto`；
**按 flexbox 规范，overflow 非 visible 的 flex item 自动最小尺寸为 0**，于是被内容挤扁。
（滚动时更明显：页签 z-index 4 < 吸顶栏 20，直接滑到顶栏背后。）

修法：`.tabs` 显式 `flex:0 0 auto` + `min-height:46px`。
判定：修复前 `tabs.h=0`，修复后 `tabs.h=46`（同一探针同一分辨率，改前/改后对照）。
判据：新增 `TestTabsCannotBeSquashedByFlex`（只取 `.tabs{}` 规则块断言，带剥离反证防恒真）。

顺带排查同类风险：`.content`（无 overflow）、`.table-scroll`/`.logbox`（在对 block 卡片内）都不受影响 ——
**只有 `.tabs` 同时满足「是 flex item」且「自己带 overflow」**，故只此一处。

### 缺陷 B：任务页空态摆了两张空卡（体验缺陷）

三张卡里两张只写「队列是空的」「当前没有执行中」，而此刻唯一能做的事（加任务）还藏在折叠里。
改法：全空时**只留一张卡** = 一行状态摘要（排队/执行中/今日产出）+ 一句解释「引擎会自动从模板生成，
不需要你手动加」+ **直接摊开**的填表。有任务时才回到表格 + 折叠表单。
判据：新增 `TestQueuePageHasActionWhenEmpty`（全空分支必须存在、表单不得被 fold 包住）。
