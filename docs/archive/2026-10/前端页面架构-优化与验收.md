# 前端页面架构优化与验收（2026-10-19）

> 目标：优化前端页面架构。首页只留一个自动按钮；子页面由实现者决策但需功能完整、交互流畅、
> 与首页视觉统一；整体响应式；首页按钮有状态反馈与加载动画；子页面遵循性能优化标准；
> 完工需验证「首页无多余元素 + 自动按钮正常 + 子页面自洽 + 无交互冲突/样式异常」。

## 0. 范围

改的是「个人 AI 工作台」的 Web 前端：`workbench/internal/web/`（Go 内嵌静态资源，随单个 EXE 发布，零外部依赖）。

| 路由 | 页面 |
|---|---|
| `/` | 首页（开屏页） |
| `/admin` | 管理面板（10 页签） |
| `/governance` | 治理控制台 |
| `/modelpool` | 模型池 |

## 1. 首页只剩一个自动按钮（要求 1 + 3）

**改动前**：可见元素三块 —— 徽标文字、状态行「引擎状态：…」、主按钮。
**改动后**：可见元素只有主按钮；另外两处（读屏状态、后门）分别用 `.sr-only` 与
`color:transparent` 做到视觉不可见但可达/可读。

按钮自带的自动行为（`assets_script.go` 首页段）：

| 特性 | 实现 |
|---|---|
| 自动加载 | 脚本执行即 `paint('busy')`，不等网络返回就进入加载态 |
| 自动响应 | 每 4s 轮询 `/api/status`，把引擎阶段收敛为按钮状态 |
| 自动触发 | 开屏 900ms 后若「待启动/已停止」，自动点一次（仅一次，失败不循环） |
| 防重入 | `inflight` 标志；连点 5 次只发 1 次 `/api/engine/start`（实测） |
| 失败收敛 | 连续 3 次状态读取失败 → `error` 态，文案「重试」并允许手动重试 |
| 状态反馈 | 6 态 `idle/busy/running/paused/stopped/error`，各有文案/配色/aria |
| 加载动画 | 左 `.btn-spinner`（仅 busy）+ 右 `.btn-arc`（仅 running），由 `data-state` 控制 |
| 无障碍 | `aria-busy`、`aria-describedby` 指向 `role="status"` 的 `.sr-only` |
| 减少动效 | `prefers-reduced-motion` 下动画归零，加载环保留静态描边 |

### 实测（CDP 直连 headless 浏览器，无中间层）

自动触发全链（先用接口把引擎停到 stopped，再加载页面）：

```
t0      stopped  重新启动   disabled=false  aria-busy=false  spinner=0  arc=0  live=引擎已停止
600ms   running  运行中     disabled=true   aria-busy=false  arc 由 0→1 过渡中   live=引擎运行中
```

**页面加载本身就把 idle 引擎拉到了 running**（接口侧复核：`phase: idle → running`；
探针另用 `api/status` 侧记录到引擎 envelopes/审计行随之产生）。

状态反馈的诚实性（本轮修掉过一个假象）：

```
运行中（稳定）    spinner=0  arc=1     ← 只有运行环
停引擎后 1400ms   spinner=0  arc=0     ← 停止态没有任何旋转环（不是「在加载」）
单次手动点击      spinner 由 0.53→0，arc 由 0→1   ← 回到运行态
```

## 2. 子页面（要求 2）

子页面「同壳不同体」：三个子页面共用同一套顶栏（`topbar/brand/topactions`）、
按钮体系（`.btn/.btn.ghost/.btn.danger`）、卡片、KV、状态色与 `app.css`；功能模块按业务设计：

- **管理面板** 10 页签：概览 / 队列 / 产出 / 模板 / 自主 / 评估 / 日志 / 治理 / 工作目录 / 设置。
- **治理控制台**：契约 × 体量双线，卡片读数 + 分级横幅（ok/warn/red/unknown）。
- **模型池**：概览 + 车道水位 + 模型清单 + 添加/编辑 + 运行日志。

每个子页面都有「回首页」与「管理面板」链接，并声明 favicon。

## 3. 响应式（要求 3）

断点：`≤480` 手机 / `≤720` 平板竖屏 / `≤1080` 小笔电 / `≥1600` 宽屏；
外加 `max-height:520px`（手机横放）与 `pointer:coarse`（触屏 44px 基线）。

首页按钮不依赖断点：`width:min(260px,72vw)` + `font-size:clamp(22px,5.4vw,30px)`，
360–1920px 连续缩放。

子页面结构重排：顶栏 ≤720 换行；页签条横向滚动（隐藏滚动条）；`.row` 纵向堆叠；
`.grid.c2/.c4` 收单列；模型池 9 列表格 ≤720 改**卡片式**（`data-label` + `td::before` 显示字段名，
而不是横向滚动 —— 触屏上横滚会让「操作」列永远够不到）；窄屏表格 `table-layout:fixed` +
`overflow-wrap:anywhere`。

## 4. 性能（要求 3）

- 全部资源内嵌二进制，无第三方 CDN/字体/框架。实测首页：`app.css 11.8 KB (4ms)`、
  `app.js 65.4 KB (4ms)`、`favicon.svg 0.5 KB (1ms)`；`navMs 30.6 / domMs 30`。
- 静态资源缓存 = `no-cache, must-revalidate` + `ETag`（实测条件请求 304、正文 0 字节）；
  HTML = `no-store`（带 token）。

> **这里有一个被实测纠正的设计错误（见 §6.3）**：最初写成 `max-age=31536000, immutable`，
> 看似「性能最优」，实际让升级后的旧资源一年不失效，连本次验收读数都变成了缓存副本。

## 6. 本轮修掉的四个真缺陷（全部由实测抓出，含一个我自己的设计错误）

### 6.1 模型池页面 token 从未注入（`injectFmt` 误命中 CSS 百分号）

`pool_page_render.go` 的 `injectFmt` 按「第一个 `%`」替换，而窄屏 CSS 里有 `width: 100%;`，
于是 token 被塞进 CSS（页面出现 `100;<token>`），`window.__WB_TOKEN__` 成了空串，
**所有 `/api/pool` 请求 401**（浏览器实测：`加载失败：unauthorized`）。
修复：只替换 `%s`。回归用例 `TestPoolPageTokenInjectionWithCssPercent`。

### 6.2 窄屏审计日志把页面撑出横向滚动

390px 下「日志」页签内容宽 381 > 容器 390（临界），根因是表格按内容自动列宽。
修复：窄屏 `table-layout:fixed` + `overflow-wrap:anywhere`。
回归用例 `TestNarrowScreenTablesCannotOverflowPage`。

### 6.3 我自己的缓存策略错误：`immutable` 让验收读数变成缓存副本

`serveAsset` 最初写 `Cache-Control: public, max-age=31536000, immutable`。
后果：改完 CSS 后浏览器**不再发请求**，页面仍是旧样式 —— 探针连续多轮读到
「stopped 态还显示加载环」，其实是旧 CSS 的响应，差一点把一个已修好的行为判成缺陷。
修复：`no-cache, must-revalidate` + ETag（仍保留 304、正文 0 字节）；
探针每次运行使用独立浏览器 profile（`cdp-profile-<ts>`）。
回归用例 `TestAssetCacheAndETag`、`TestAssetPolicyKeepsPagesAndAssetsInSync`。

### 6.4 favicon 404 污染「加载是否干净」的读数

浏览器会请求 `/favicon.ico`，缺失在 DevTools 留下 404（探针 `runtimeErrors=1`）。
修复：内嵌 SVG 图标（`favicon.go`）+ 四页面声明 `rel="icon"` + `/favicon.ico` 回 204。
实测：`runtimeErrors` 由 1 → 0；`TestPagesDeclareFavicon` 守护。

## 7. 取证方式说明

`agent-browser` 在本机其守护进程会挂起（`eval` 长时间无返回）。
按「取不到数 ≠ PASS」的纪律，最终取证改走两条确定性路径：

1. `tests/ui/cdp_probe.mjs` —— Node 直连 CDP，无守护进程、无长驻会话，超时即标 UNVERIFIED；
2. `tests/ui/dom_probe.ps1` —— Edge `--headless --dump-dom`，一次性抓渲染后 DOM。

两者都在最终修订版上跑通，本文档的实测值来自它们。
