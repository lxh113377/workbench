# 质量问题根因铁证：协议示例的中文方括号（2026-10-19 19:0X · ds 端，请 Lead 优先处理）

## 一句话
`internal/artifact/protocol.go:32` 给模型的示例命令被中文方括号【】包裹，
模型照抄后命令被切碎、必然验收失败，是返工率高的**共同上游根因**。

## 铁证 1：产品真实渲染（Go 测试写出，非手工转写）

模型实际看到的协议文本第 4 条：

```
4. 若不产出代码，也要产出至少一个 .md 成果文件，并用
   pwsh -NoProfile -Command 【if (Test-Path a.md) { exit 0 } else { exit 1 }】
   这类命令证明文件真的存在。
```

## 铁证 2：照抄后的切分结果（容器内实测复现）

输入（模型照抄 + Lead 18:51 的 forceNonInteractive 注入后）：

```
pwsh -NonInteractive -NoProfile -Command 【if (Test-Path a.md) { exit 0 } else { exit 1 }】
```

`splitCommand` 输出：

```
["pwsh" "-NonInteractive" "-NoProfile" "-Command" "【if" "(Test-Path" "a.md)" "{" "exit" "0" "}" "else" "{" "exit" "1" "}】"]
```

`argv[4]` 是 `【if` 而不是完整脚本 ⇒ pwsh 拿 `【if` 当命令名 ⇒
`术语 '【if' 不会被识别` ⇒ 验收必败 ⇒ 返工。

## 影响面（对应 R17 的三类失败）
1. **命令畸形**（现场 1 例 `\if: 术语不识别`）—— 反斜杠变体；
2. **无验收命令**（4 例）—— 模型看示例不可用，干脆不写 verify；
3. **产出过短**（5 例）—— 模型放弃协议输出，只给一句话。

三类共同上游都是这条示例。修它一项，三类齐降。

## 修复（5 分钟改动，一行）
把 protocol.go:32 的示例改成**不带【】、明示引号必须保留**：

```go
"4. 若不产出代码，也要产出至少一个 .md 成果文件，并用下面这条命令原样证明文件存在\n" +
"   （引号必须保留，不要改写、不要加转义、不要加方括号）：\n" +
"   pwsh -NoProfile -Command \"if (Test-Path a.md) { exit 0 } else { exit 1 }\"\n" +
```

同时在"硬性要求"加一条：
```
6. cmd 必须是可直接执行的命令行：以 python/node/pwsh/go 开头，
   禁止把说明文字写进 cmd，禁止给命令加【】等装饰字符。
```
