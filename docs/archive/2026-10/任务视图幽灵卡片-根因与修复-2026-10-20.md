# 「任务视图里一堆个人 AI 工作台、关不掉」：根因与修复（2026-10-20）

> 老大现场：任务视图（Win+Tab）右侧十几张同名「个人 AI 工作台」白卡，没有预览内容，点不开也关不掉。
> 直接问：**我这里看到的是什么，关不掉。**

## 一、那是什么

**不是进程，也不是窗口实例** —— 是每个 workbench 实例的**托盘消息窗口**（tray message window）。

`workbench/internal/tray/tray_windows.go` 里为了收托盘图标的消息，创建了一个窗口：

```go
h, _, _ := procCreateWindowExW.Call(
    0, ...className..., ...title...,
    0, 0, 0, 0, 0, 0, 0, uintptr(hInst), 0,   // ← 第 1 个参数 exStyle = 0
)
```

第一个参数是 `dwExStyle`，传的是 **0**，也就是**没有 `WS_EX_TOOLWINDOW`**。
于是 Shell 把它当成一个**普通应用窗口**收录进 Alt-Tab / 任务视图。

实测取证（本次现场）：

```
hwnd=18615588 pid=41448 style=0x04C00000 exstyle=0x00000100 TOOLWINDOW=False owner=0 title=个人 AI 工作台
```

- `style=0x04C00000` = WS_CLIPSIBLINGS|WS_BORDER|WS_CLIPCHILDREN（**没有 WS_VISIBLE**，所以它是隐藏的）
- `exstyle=0x00000100` = WS_EX_WINDOWEDGE（**没有 WS_EX_TOOLWINDOW=0x80**）
- `TOOLWINDOW=False` → 任务视图收录

**为什么"关不掉"**：它是纯消息窗，没有可见内容、也没有关闭语义。任务视图里的卡片是 Shell 对"曾经存在过的应用窗口"的缓存条目；实例进程被强杀后，这个条目的缓存不随之清掉，所以点 X 也没用。

## 二、为什么之前会有那么多张

正是上一轮修掉的那个根因：**实例死了没有回收者**（四条拉起链 + 零回收）。每个被拉起的实例都注册一张托盘窗卡片，实例堆到约 24 个，卡片就堆一排。上一轮修了实例回收（`tests/instance_guard.ps1` + keepalive 每分钟一跳），卡片不再新增；但**已存在的老卡片是 Shell 缓存，不会因为进程消失而自动清掉**。

## 三、修了什么

### 1. 源码修复（`workbench/internal/tray/tray_windows.go`）

| 改动 | 值 | 作用 |
|---|---|---|
| CreateWindowExW 的 dwExStyle | 0 → WS_EX_TOOLWINDOW (0x80) | 工具窗**不进** Alt-Tab / 任务视图 |
| dwStyle | 0 → WS_POPUP (0x80000000) | 配合工具窗，Shell 彻底当 popup 处理 |
| 创建后 | 新增 SetWindowPos(..., SWP_HIDEWINDOW) | 双重保证永不显示 |
| 窗口标题 | opts.Title → 个人 AI 工作台（内部消息窗口，请忽略） | 万一又被第三方 Shell 插件收录，用户看到的是"内部窗口"而不是一个像应用的入口 |
| 类名 | 提成常量 trayWindowClassName | 取证工具/测试/后续排障按类名找窗口，改名必须同步 |

**刻意不加 `WS_EX_NOACTIVATE`**：托盘右键菜单要靠 `SetForegroundWindow(自身)` 才能正常弹出与失焦收起，加了会让菜单卡在屏上关不掉（这本身就是另一个"关不掉"）。这条已写进代码注释。

### 2. 已存在的老卡片：重启 explorer

任务视图缓存属于 explorer 进程，重启 explorer 即重建缓存（**explorer 会自动重启，桌面/任务栏几十秒内回来；不丢文件、不关掉其他应用**）。

执行记录：explorer pid=12128（跑了 28.5h）→ 强杀 → 系统自动拉起 pid=38208。

## 六、边界

- **老卡片的清理依赖 explorer 重启**：Windows 没有公开 API 定点删除任务视图里的历史条目。本次已重启一次；今后只要不再堆积实例（上一轮已修），就不会再新增卡片。
- 若老大看到的是**当前**实例的卡片（而非历史残留），那是 explorer 收录发生在旧产物时期，重启 explorer 后不会再出现。
- 托盘图标本身仍在（Shell_NotifyIconW 注册未受影响），只是它的**宿主窗口**变成工具窗；右键菜单功能未改（刻意不加 NOACTIVATE 就是为它）。
