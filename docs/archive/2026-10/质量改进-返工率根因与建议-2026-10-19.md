"其他真实失败"的细分（挖样本）：
1. **模型把说明文字当 cmd**（如 `Python 自测脚本 实现模拟接口 analyze() ...` ⇒ exit 2）—— 协议误解；
2. **产物结构缺陷**：围栏未闭合（输出被截断）/ 重复文件块 / manifest JSON 语法错；
3. **真代码 bug**（如 tool.py 的 logging 格式串语法错）—— **这是返工环正常工作的证据**，该留。

## 根因判定
核心瓶颈是**模型对 ARTIFACTS 协议的遵从率**，不是某个单点缺陷。诱因在
`internal/artifact/protocol.go:32`：

```
4. 若不产出代码，也要产出至少一个 .md 成果文件，并用
   pwsh -NoProfile -Command 【if (Test-Path a.md) { exit 0 } else { exit 1 }】
   这类命令证明文件真的存在。
```

**示例命令被中文方括号【】包裹**。模型照抄时：
- 可能连【】一起抄进 cmd（必然失败）；
- 可能漏掉引号（pwsh 报错）；
- 可能"过度转义"成 \\"（命中缺陷6，1 例）。

## 改进建议（按性价比排序，归 Lead）

### P0-1 协议示例去掉【】，明示引号必须保留（改 protocol.go，5 分钟）
```
4. 若不产出代码，也要产出至少一个 .md 成果文件，并用下面这条命令原样证明文件存在
   （引号必须保留，不要改写、不要加转义）：
   pwsh -NoProfile -Command "if (Test-Path a.md) { exit 0 } else { exit 1 }"
```
同时在"硬性要求"里加一条：**cmd 必须是可直接执行的命令行，禁止把说明文字写进 cmd**。

### P0-2 splitCommand 加反斜杠归一化（改 verify.go，1 行）
`runOne` 里 `splitCommand` 前加：
```go
c.Cmd = strings.ReplaceAll(c.Cmd, "\\\"", "\"")   // 残留的 \" 还原成 "
```
（回归测试已备：tests/regression/split_backslash_escape_test.go）

### P1-1 对"自然语言 cmd"做前置体检（改 verify.go，约 10 行）
cmd 里出现连续中文且不含解释器名前缀时，直接判 `Skipped: cmd 不是可执行命令`，
不要真去 exec（省一次无谓的进程启动 + 更清晰的返工指令）。

### P1-2 产出过短的门禁从"返工"改为"返工 + 明示最低字数"
现在返工 prompt 已带"124 字，最少需要 200 字"，可再补一句"直接输出完整文件，不要解释"。
