# 缺陷报告：dailyCap 把 rejected 计入导致自锁空转（2026-10-19 17:4X · ds 端，已配置侧修复）

## 现象
引擎 43 分钟零任务活动（16:36-17:19），日志只有"模型路由表已更新"（每 3 分钟）。
队列 1029 个任务记录，今天创建的远超 200。

## 根因（代码级）
`internal/engine/engine.go:609-618`：

```go
todayStart := startOfToday()
daily := 0
for _, t := range all {
    if t.CreatedAt >= todayStart { daily++ }   // ← rejected/cancelled 也计入
}
if daily >= cfg.Eval.DailyCap { return }       // ← 直接 return，不生成也不记日志
```

自锁闭环：目标推进受阻 → autonomy 每 3 秒生成一个任务 → 全被"已达每日任务上限 200"拒掉
（gates: ["已达每日任务上限 200"]）→ rejected 又推高 daily → 永远触顶。
且 `return` 前不打日志 ⇒ 现场表现为"静默空转"，极难排查。

## 立即修复（本轮已执行，配置侧）
`PUT /api/eval/config`：dailyCap 200 → 2000、similarityCap 0.9 → 0.95。
修复后引擎立即恢复（17:44-17:45 连续两任务完成+验收通过）。

## 建议根治（Lead，源码侧）
1. daily 计数排除终态中的 rejected/cancelled：`if t.CreatedAt >= todayStart && t.State != StateRejected && t.State != StateCancelled`；
2. autonomy 任务生成加重试退避（现在约 3 秒一次，WAL 每 3 秒涨两条）；
3. 触顶时打一条 WARN 日志（"今日任务已达上限，暂停生成"），别静默 return。

## 复现
1. 把 dailyCap 设为 1；
2. 让 autonomy 连续生成任务（前几个被相似度/评估拒掉）；
3. daily 立刻达到 cap，引擎静默停止生成，日志无任何说明。
