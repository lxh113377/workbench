## 2. 架构位置

```
cmd/workbench/main.go
  ├─ --governance <status|sample|checklist|json|budget|transition>   只读/受控写出口
  └─ runApp
       ├─ supervisor.Manager  ──┐（资源采样）
       ├─ engine.Engine  ───────┤（业务/运营指标：TasksToday/Backlog/AvgCycle/FailureRate/Concurrency）
       │                        ↓
       └─ gov.Engine ── 采样 → gov.Store ──→ Summary / Alerts / Adjustments / Linkage
                                ↓
                          web.Server
                            ├─ /governance          独立治理控制台（gov.js）
                            ├─ /admin#governance    管理面板治理页签（app.js 内 renderGovernance）
                            └─ /api/gov/*           7 组接口（全部需 X-WB-Token）
```

## 4. 三条不可让渡的判据底线

1. **零数据不记 PASS**：无采样 ⇒ 总等级 `unverified`，CLI 退出码 3（不是 0）。
2. **取不到数 ≠ 取到 0**：资源域指标 v≤0 一律 unverified；零活动态吞吐 0 也 unverified，
   但有任务却 0 吞吐立即判红。两条都有测试锁定。
3. **自动调整不自动改阈值**：红区只写审计建议，阈值变更必须走 API 并回显生效值——
   自动放宽阈值等于自废判据。
