# 【α 约定裁决（2026-10-25 round 163，自行裁决，不回落给用户）】
#   背景：--accent-soft 曾定义为 rgba(var(--accent-rgb),.14) 且**零引用**，是「机制在、没人用」的假象；
#   当时的疑点是「半透明主色底该不该收编成一个固定 α 令牌」。
#   实测证据：仓库里半透明主色底共 **50 处使用、36 个不同 α**（.055 分隔线 / .075 背景晕 / .14 ≈ 0 /
#   .20 focus 环 / .32 选区 / .42 滚动条 / .55 光晕 / .66–.95 活动环 …），而 α 恰好 .14 的有 **0 处**。
#   裁决：**不设固定 α 令牌**；半透明主色底一律按语义**现写** rgba(var(--accent-rgb), α)，
#   理由：36 个 α 承载的是不同语义层级，收编成单一固定 α 的令牌既覆盖不了（.14 命中 0），
#   又会制造第二个「一处定义、多处不同值」的骗人机制 ⇒ 删掉定义才是诚实解（零引用、零读取，删除无风险）。
#   承重性核对：无任何测试/门禁断言它存在（grep workbench/internal/web 与 setup/、tests/ 只命中定义行与本表）；
#   check_css_rgb_pair 与它无关（它只管 --accent-3/--accent-3-rgb 配对）。
