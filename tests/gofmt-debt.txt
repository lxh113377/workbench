# gofmt 格式债务登记（2026-10-22 建立）
#
# 语义：登记在此的文件仍会被 check_gofmt.ps1 **点名并计数**，但不计入 rc。
# 有豁免时门禁输出三态，绝不打纯 PASS。
#
# 【登记基准 = HEAD，不是工作区】（2026-10-22 四轮校准，这条是核心）：
#   CI 判的是 HEAD；本机工作区常被并行会话改得比 HEAD 更新（甚至本地已合规）。
#   若按工作区判，会产生两个死结：① 本地绿但 CI 红（豁免被误删）；
#   ② 本地红但 CI 绿（在途件被当违规）。故必要性一律按 HEAD 版本复算。
#
# 【失效检测同上闸】：登记但 HEAD 已不漂移 = 腐烂条目，门禁判红要求删除
#   （防止在册豁免把该文件将来的漂移永久遮住）。
# 【并行在途件不登记】：工作区漂移但 HEAD 合规的文件由门禁自动归入
#   「并行在途件，不计 rc」，无需在此列条。
#
# 清零条件：HEAD 上的漂移修复后（并行会话提交其格式化），删除对应行。
#
# 本轮账（2026-10-22 18:5x，HEAD=7375eca 实测）：33 个文件 HEAD 漂移 + 工作区皆 M（在途），
# 另 2 个 shortcut 件同在途。全部为并行会话在途，本会话不代改（避免覆盖竞争）。
